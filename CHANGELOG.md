# Changelog

## 0.1.0

First release. Versioning starts at publish.

- `SKILL.md` and `references/` follow Felix Rieseberg's essay: the four types of ambition (Speed, Altitude, Depth, Range), the QBR example, depth techniques and the deeper-version prompt, range techniques, and background.
- `npx ambitious-skill` installer: install, `uninstall`, `--project`, `--dir`, `--force`. It only removes or overwrites directories it created.
- Installer integration tests (`npm test`).
