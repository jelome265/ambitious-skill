# Workflow: research, investigate, plan, implement

Every dimension in this skill runs through four phases in order. A phase starts only when the gate of the previous phase is met. If a gate fails, go back to the phase that produced the gap. Do not skip a phase.

## 1. Research

Find what the work needs before deciding anything.

- Question 1: the steps a top professional in this field would take that the request does not ask for. Record the sources you used.
- Question 2: the rawest material available (logs, original documents, measurements). Name each one, and say where it is.
- Question 3: the methods and tools the field uses. Name each one.
- Question 4: the outside checks available. Name each one.

**Gate:** all four questions are answered in writing, each with at least one named source. If a raw source does not exist, write that down.

## 2. Investigate

Test what you think you know against the raw material.

- List each belief the request depends on.
- Test each belief against the raw data from Research.
- Record every belief that fails, and the evidence for it.
- List the gaps: what the data cannot tell you.

**Gate:** every belief has a recorded result (holds, fails, or cannot be tested), and every gap is listed.

## 3. Plan

Write the plan before doing the work.

- Rewrite the request so it asks for exactly the Research answers: the expert steps, the raw inputs, the methods, and the outside check.
- List the steps in order, with the tool each step uses.
- Name the outside check that will decide whether the result is right, and what it cannot catch.
- Name what is missing (access, data, software) and how you will get it.

**Gate:** the rewritten request and the plan are both written, and every step has a tool and an outside check.

## 4. Implement

Carry out the plan.

- Work through the steps in order. Record any change from the plan and why.
- Run the outside check from the Plan phase. Record the result.
- If the check fails, return to Investigate. Do not change the check to pass the result.

**Gate:** every step in the plan is done or recorded as blocked, and the outside check has a recorded result.

## Stop rules

- Do not start Implement until Plan's gate is met.
- Do not replace an outside check with the work's own judgment.
- Do not present a result as correct until Implement's gate is met.
