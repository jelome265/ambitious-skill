# Speed: the same work in less time

Speed is the first of the four dimensions. The essay describes it as the same work done in less time, the most common gain from these tools, and skips it because it needs little method. This reference adds the method: speed must not reduce the four answers from SKILL.md.

## Required phases

### 1. Research

- Question 1: the steps the current method takes that a faster expert would not take. Record them.
- Question 2: the raw timing data for the current method: durations, counts, and where the time goes. Name the source.
- Question 3: the faster method, and the tools it needs. Name them.
- Question 4: the check that proves the result is still correct at the new speed. Name it.

**Gate:** all four answers are written, with timing data named as the raw source.

### 2. Investigate

- List each claim about where the time goes. Test each claim against the timing data.
- Record which claims fail. A slow step is not always the one that looks slow.
- List what the timing data cannot show.

**Gate:** every claim has a recorded result, and the gaps are listed.

### 3. Plan

- Rewrite the task so it asks for the same outcome by the faster method, with the four answers stated.
- List the steps in order, with the tool for each.
- Name the outside check that proves the outcome is unchanged, and the timing measurement that proves it is faster.

**Gate:** the rewritten task and plan are written, and both checks are named.

### 4. Implement

- Carry out the plan. Record each change from it.
- Run the correctness check first. Then run the timing measurement against the baseline from Research.
- If the result is faster but fails the correctness check, it is not a speed gain. Return to Investigate.

**Gate:** the correctness check passes, and the timing result is recorded against the baseline.

## What speed must not cost

- Correctness: an outside check must still pass.
- Method: the faster path still uses the real method from Question 3.
- Scope: time saved is not a reason to add work the request did not ask for.
