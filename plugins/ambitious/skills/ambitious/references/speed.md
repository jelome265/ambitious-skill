# Speed: the same work in less time

Speed is the first of the four dimensions. The essay describes it as the same work done in less time, the most common gain from these tools, and skips it because it needs little method. This reference adds the method: speed must not reduce the four answers from SKILL.md.

## Suggested order

- **Research:** the steps the current method takes that a faster expert would not take. The raw timing data for those steps (durations, counts, where the time goes). The faster method and the tools it needs. The check that shows the result is still correct.
- **Investigate:** list each claim about where the time goes and test it against the timing data. A slow-looking step is not always the slow one.
- **Plan:** rewrite the task so it asks for the same outcome by the faster method. List the steps with their tools. Name the correctness check and the timing measurement.
- **Implement:** carry out the plan. Run the correctness check first, then the timing measurement against the baseline. A faster result that fails the correctness check is not a speed gain. Go back to Investigate.

## What to watch for in speed work

- Correctness: the outside check should still pass.
- Method: the faster path should still use the real method from Question 3.
- Scope: time saved is not a reason to add work the request did not ask for.
